# Ручное и синтетическое обогащение данных

Курсовая работа Эвелины и Милены. Сравниваем, как ручное и синтетическое обогащение данных влияет на качество и устойчивость моделей машинного обучения.

## Датасеты

| Данные | Исходный набор | Задача |
| --- | --- | --- |
| Отзывы о фильмах | IMDb, [анализ исходного набора](docs/text/text_EDA.ipynb) | Классификация тональности отзывов на положительную и отрицательную |
| Изображения винограда | Фотографии винограда, [собранные снимки](data/images/) | Разметка областей полигонами и постановка ключевых точек |

Для ручного обогащения собраны [120 отзывов для Label Studio](data/text/reviews_120_label_studio.json) и 50 фотографий винограда. Эвелина разметила [50 отзывов](annotations/evelina/text/text.json) и [49 фотографий](annotations/evelina/images/grape.json). 

## Как работаем

1. Отбираем дополнительные данные отдельно от исходных наборов и готовим задания для Label Studio. Для каждого источника фиксируем URL, дату обращения и условия использования.
2. Эвелина и Милена независимо размечают одни и те же объекты по общим правилам и фиксируют время на каждый объект.
3. Сравниваем разметку, разбираем расхождения и сохраняем согласованные метки в `annotations/agreed/`.
4. Создаём синтетические данные и оцениваем их качество.
5. Обучаем модели на четырёх вариантах данных: исходном, с ручным обогащением, с синтетическим обогащением и с обоими видами обогащения. Сравниваем качество и устойчивость моделей.

## Структура папок

```text
annotations/
  evelina/      разметка Эвелины
  milena/       разметка Милены
  agreed/       согласованная разметка
data/
  text/         отзывы для Label Studio
  images/       фотографии винограда
docs/
  text/         ноутбук с анализом IMDb
  images/       ноутбук с анализом изображений
```

В папке каждого аннотатора есть подпапки `text/` и `images/`. 

Для ноутбука IMDb используются Jupyter, pandas, matplotlib и scikit-learn. Перед запуском ячеек нужно загрузить исходный IMDb в DataFrame `df` со столбцами `review` и `sentiment`.
